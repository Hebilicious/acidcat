The tool turns a folder of Markdown files into a static site. It writes one HTML file for each page.

## Who it is for

Teams that write documentation next to their code. The pages live in the same repository as the code, and a pull request changes both.

## What you need

- Node.js 24 or later.
- A package manager: pnpm, npm or Yarn.
- A folder of Markdown files.

Go on to [installation](/guide/installation/).
