Example Docs is a small documentation site. Each page has the same content in each framework, so a reader of the benchmark compares the frameworks and not the content.

![A drawing of a lighthouse on a hill at night](./hero.png)

The guide tells how to install the tool, how to configure it, and how to deploy a site. The reference gives the API, the command line and answers to common questions.

Start with the [introduction](/guide/).
