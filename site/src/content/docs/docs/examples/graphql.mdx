<FileLink file="apis/graphql.ts" /> is application code on a session: `query { status }`, mutations that return the new status, and `subscription { statusChanged }`. A failure is a member of a union, for example `Status | Offline | PoweredOff`. <FileLink file="apis/schema.graphql" /> is the schema. The API also serves the HTTP binding at `/api`.

Run it from `examples/aircon`. It listens on `http://127.0.0.1:3000`:

```sh
node apis/main.ts graphql
curl http://127.0.0.1:3000/graphql -H 'Content-Type: application/json' -d '{"query":"mutation { setPower(on: true) { __typename } }"}'
```
