<FileLink file="apis/mcp.ts" /> serves two tools at `/mcp`: `get_status` and `set_controls`. `Mcp.withEvents` from `@acid-cat/core-effect` adds the [MCP events extension](/spec/bindings/mcp/#events) for `aircon.status.changed`. The API also serves the MCP binding at `/capabilities/mcp` and `/capabilities/mcp-legacy`.

Run it from `examples/aircon`. It listens on `http://127.0.0.1:3000`:

```sh
node apis/main.ts mcp
```
