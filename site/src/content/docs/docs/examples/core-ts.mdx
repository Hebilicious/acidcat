<FileLink file="core-ts/aircon.ts" /> defines the application with `@acid-cat/core-ts` and Zod. Each other file of `core-ts/` serves it through one binding: <FileLink file="core-ts/cli.ts" />, <FileLink file="core-ts/mcp-stdio.ts" />, <FileLink file="core-ts/serve.ts" /> and <FileLink file="core-ts/page.ts" />.

Run it from `examples/aircon`:

```sh
node core-ts/cli.ts aircon power set --on
node core-ts/cli.ts list
node core-ts/serve.ts 0.0.0.0:8080
AIRCON_URL=http://localhost:8080/cli node core-ts/cli.ts aircon status get
```

Give this command to an MCP client, with the root of the repository as its working directory:

```sh
node examples/aircon/core-ts/mcp-stdio.ts
```
