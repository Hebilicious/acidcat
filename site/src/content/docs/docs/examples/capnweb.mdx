<FileLink file="apis/capnweb.ts" /> is a class with typed methods. `followStatus(listener)` calls the function of the client with each new status, until the client disposes the result. A failure is `{ ok: false, error }`.

Run it from `examples/aircon`. It listens on `http://127.0.0.1:3000`, and on `ws://127.0.0.1:3001/rpc`:

```sh
node apis/main.ts capnweb
```

A client:

```ts
import { newWebSocketRpcSession } from "capnweb";
import type { AirconApi } from "./apis/capnweb.ts";

using api = newWebSocketRpcSession<AirconApi>("ws://127.0.0.1:3001/rpc");
using following = await api.followStatus((status) => console.log(status));
await api.setPower(true);
```
