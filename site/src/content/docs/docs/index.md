title: Introduction

---

AcidCat lists the operations of an application once, in a **catalog**. Each surface comes from it: a command line, an MCP server, an HTTP API and typed client code.

Read the [specification](https://github.com/Hebilicious/acidcat/blob/main/spec/README.md) and the [packages](https://github.com/Hebilicious/acidcat/blob/main/packages/README.md) on GitHub.
